# Glossário — Arkon

| Termo no jogo | Significado real |
|---|---|
| **Influência** | Moeda política — quem você conhece |
| **Ficha** | Reputação pública na facção |
| **Gradus** | Nível do personagem (1–200+) |
| **Ars** | Especialização de arma |
| **O Pleito** | Eleição de 4 em 4 anos com violência |
| **Damnatio** | Delete irreversível do Tridente |
| **Impeachment** | Missão de traição para tomar cargo |
| **Acordo de Cavalheiros** | Protocolo secreto entre os dois deuses |
| **Protocolo Cinza** | Nome oficial do Acordo de Cavalheiros |
| **Niflheim** | Zona oculta dentro do Bifrost Inferior |
| **Eidolon** | Anomalias — fragmentos do código de Kobi |
| **Diminutio** | Penalidade de decaimento de Ficha por inatividade |
| **Runa-Arché** | O código fundamental da magia |
| **Ginnr** | O vazio antes da criação |
| **Aevum** | A era antes do sacrifício de Kobi |
| **Manaphis** | Criaturas soltas por Molusk nos dutos de Skálholm |
| **Deserti** | Desertores capturados, usados como trabalho forçado pela Gestão |
| **Nó IX** | Duto estratégico sob o Bifrost controlado por Drena |
| **id_fluxo** | Identificador interno de Influência no sistema |
| **Bifrost Inferior** | O Grande Túnel — única passagem entre os dois lados |
| **Ordo Bifrost** | Organização que cobra pedágio e controla o Túnel |
| **Consilium Novem** | 9 cadeiras da cúpula do Bonde da Base |
| **Legati** | 3 cargos da cúpula d'A Gestão |
| **Tridente de Kobi** | Artefato legado — interface de admin disfarçada de arma |
| **Bifurcum** | Comando do Tridente: divide um recurso em dois (Fork) |
| **Conflatio** | Comando do Tridente: funde duas zonas (Merge) |
| **Damnatio** | Comando do Tridente: apaga zona permanentemente (Delete irreversível) |
